## 1. Что такое модель Sphera

Модель Sphera — это **один файл `.sm`** (обычно 1–10 МБ), внутри которого:

- **N-граммы** (статистика, какое слово идёт после какого)
- **Словарь** всех использованных слов
- **Определения** терминов (для запросов «что такое X»)

`.sm` — это сжатый бинарник, читать глазами его не нужно. Модель
собирается из **трёх текстовых файлов**, которые вы пишете сами:

| Файл | Что это | Сколько строк |
|---|---|---|
| `seeds.txt` | Список терминов (тем) | 50–5000 |
| `dialogs.txt` | Пары «вопрос → ответ» | 100–10000 |
| `config.json` | Параметры сборки | 1 файл |

После сборки вы получаете `my-model.sm`, который:
- запускается командой `sphera.exe run my-model`
- работает как HTTP API: `sphera.exe serve my-model`
- загружается на GitHub для других пользователей
